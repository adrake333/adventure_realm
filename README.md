About this project:

Adventure Realm is a basic adventure game where you will explore a fantasy world. Fight enemies, find treasure, and complete quests.

It is very basic as this is my first project being handmade from scratch.



--- To Play ---
General Requirements:
1. Ensure you have Python 3 and Git installed on your system.
2. Clone the repository to your system.
3. use "python3 main.py" from project root"

Windows:
1. Install Git for Windows from git-scm.com.
2. Open Git Bash from your Start menu.
3. Type cd Documents and press Enter.
4. Type "git clone https://github.com/adrake333/adventure_realm" and press Enter.

Mac:
1. Open Terminal using Command + Space and typing Terminal.
2. Type cd ~/Documents and press Enter.
3. Type "git clone https://github.com/adrake333/adventure_realm" and press Enter.
4. If prompted, click Install for Command Line Tools.

Linux:
1. Open your terminal window.
2. Type sudo apt install git and press Enter.
3. Type cd ~/Documents and press Enter.
4. Type "git clone https://github.com/adrake333/adventure_realm" and press Enter.
